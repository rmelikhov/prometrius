# Практикум по мониторингу с Prometheus + Grafana

## Цель практикума
Научиться настраивать мониторинг Java приложения с использованием:
- **Prometheus** - для сбора метрик
- **Grafana** - для визуализации

## Архитектура стенда
- **Демо приложение**: http://localhost:8080
- **Prometheus UI**: http://localhost:9090  
- **Grafana**: http://localhost:3000 (логин: admin/admin)

## Что вы узнаете:
1. Как работают метрики Java приложения
2. Как настроить сбор метрик в Prometheus
3. Как создавать дашборды в Grafana

Нажмите "Start Scenario" чтобы начать!
